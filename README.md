# Image Converter & Compressor

## 🇫🇷 Version Française

Ce projet est une **application web 100% frontend** développée avec React/Vite.  
Elle permet aux utilisateurs de **convertir et compresser leurs images directement dans le navigateur**, sans qu’aucune donnée ne soit envoyée ou stockée sur un serveur externe.  

L’objectif est de fournir une solution simple, rapide et respectueuse de la confidentialité pour optimiser les images avant leur utilisation en ligne.

---

### 🚀 Stack technique
- React.js + Vite
- Tailwind CSS + DaisyUI
- JavaScript / TypeScript
- **Bibliothèque de compression/convertisseur d’images côté navigateur** (ex. `browser-image-compression` ou `compressorjs`)

---

### ✨ Fonctionnalités principales
- Compression d’images (JPEG, PNG, WebP)  
- Conversion entre formats d’images  
- Traitement **local** (aucune image stockée sur un serveur)  
- Interface moderne et responsive  
- Téléchargement des images optimisées en un clic  

---

### 🌐 Démo en ligne
👉 [Voir l’application](https://landrytech.vercel.app/)

## 🇬🇧 English Version

This project is a **100% frontend web application** built with React/Vite.  
It allows users to **convert and compress images directly in the browser**, with no data sent or stored on any external server.  

The goal is to provide a simple, fast, and privacy‑friendly solution to optimize images before using them online.

---

### 🚀 Tech Stack
- React.js + Vite
- Tailwind CSS + DaisyUI
- JavaScript / TypeScript
- **Image compression/conversion library for browser** (e.g. `browser-image-compression` or `compressorjs`)

---

### ✨ Key Features
- Image compression (JPEG, PNG, WebP)  
- Format conversion between images  
- **Local processing** (no server storage)  
- Modern and responsive interface  
- One‑click download of optimized images
